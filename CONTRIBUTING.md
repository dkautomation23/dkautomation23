# Contributing

This repository holds the profile page shown at
<https://github.com/dkautomation23> — a README and nothing else.

Corrections are welcome: a dead link, a tool described in a way that no longer
matches what it does, a number that has moved. Open an issue with what is wrong
and what it should say.

Everything else — features, bugs, security reports — belongs in the repository
of the tool itself. The profile only points at them.
